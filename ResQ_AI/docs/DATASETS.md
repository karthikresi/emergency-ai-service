# Datasets

This package is built around a synthetic prototype dataset that mirrors the expected ResQ schema and label families.

## Dataset inventory
- resq-hybrid-synthetic-v1 — synthetic prototype dataset for local validation
- public benchmark references — used only for research and text-pattern comparison

## Compatibility notes
- The synthetic prototype is intentionally schema-aligned to the ResQ emergency dispatch use case.
- Public benchmark datasets were not merged blindly; label mappings are documented separately.
