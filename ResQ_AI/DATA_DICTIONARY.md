# Data Dictionary

| Column | Type | Description |
|---|---|---|
| emergency_text | text | Raw emergency description |
| category | categorical | Target category | 
| severity | categorical | Target severity |
| required_skills | categorical | Required responder skill(s) |
| responder_roles | categorical | Multi-label responder response set |
| latitude | numeric | Incident latitude |
| longitude | numeric | Incident longitude |
| location | categorical | Human-readable location |
| timestamp | datetime | Event timestamp |
| context | text | Context summary |
